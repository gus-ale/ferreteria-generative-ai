# Security Policy

## Supported version

The `main` branch is the supported portfolio version.

## Reporting

Do not publish API keys, passwords, customer data, or exploit details in a
public issue. Contact the repository owner privately and include:

- Affected component.
- Reproduction steps without real secrets.
- Expected impact.
- Suggested mitigation, if known.

Rotate any credential that may have been exposed.

## Scope

This repository uses synthetic demonstration data. It is not a production
authorization system and must be hardened before handling real customer data.
